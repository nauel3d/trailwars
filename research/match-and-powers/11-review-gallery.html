SUN WINS THE CIRCUIT

Final match placement is distinct from surviving one round. Play Again returns to a fresh roster/ready flow; no automatic currency or rank stakes.

Each surviving-opponent point is settled by the server once. Animation explains a completed ledger; it never creates points.

Read the sequence: show the previous total → reveal this round's delta → fill the progress bar → move each row once to its new place. Ties display equal ranks; stable row order is presentation, not a tie-break rule.

Keep the current HUD quiet during play. Inter-round movement uses the existing 0.30s reorder and 0.46s celebration tokens. Reduced motion jumps to the settled state. Hiding this page cancels pending timers; Replay restarts explicitly.

This gallery reuses existing Trail Wars artwork and palette. It proposes a data/story sequence, not a new visual direction. Prototype rules, overtime policy and future powers require approval before any default mode changes.
